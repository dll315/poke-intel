# 首版验证记录

验证日期：2026-10-04。运行环境：Windows、Node 24.19.0、Chromium。

## 已实际验证

- `npm test`：35 项全部通过，覆盖 API、SQLite、加密设置、企业微信队列、管理员 CLI 与备份恢复。
- `npm run test:ui`：9 项真实浏览器测试全部通过，使用独立 Fastify 服务与 SQLite 数据库。
- `npm run build`：TypeScript 检查与 Vite 生产构建成功。
- `npm run test:production`：构建后的 HTML、SPA 路由、JSON API 404、Secure/HttpOnly/SameSite Cookie、生产 CSP 均通过。
- `npm audit --omit=dev`：生产依赖零已报告漏洞。
- 本地构建预览：桌面 1440 宽与手机 390 宽截图检查完成，无页面脚本异常、无手机横向溢出。

## 验收覆盖

公开浏览、历史筛选与共享网址、邮箱密码注册登录登出、上报待审与私有列表、审核通过/驳回、同地点 15 分钟内合并、不同地点及时间边界保留、过期/手动结束、纠错/编辑、用户停用/恢复、最后管理员保护、会话过期、Origin/CSRF、中文字段验证、分钟/每日限流、代理 IP 限流边界、真实数据库重开、Alphapedia 同步与中英文搜索、企业微信密文设置与动态切换、通知去重和重试、WAL 在线备份和确认恢复，均有测试覆盖。

浏览器测试还覆盖中文名称与英文原名展示、推送设置保存/测试/停用/清除、移动布局和网络失败重试、管理员实际审批和公开历史、编辑对话框内的错误提示、迟到列表请求、跨账号私有数据隔离、重复点击当前管理标签、审批未完成时禁止管理标签切换。

独立审查发现并修复了代理共用限流、两类会话撤销并发问题、CLI 审计遗漏、管理列表类型混淆、空可选字段、私有列表缓存泄漏、对话框错误被遮挡及审批中切换标签问题。相应回归测试先复现失败后通过。最终限定复核没有遗留发现。
