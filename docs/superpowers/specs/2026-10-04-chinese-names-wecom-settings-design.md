# 中文名称与企业微信设置设计

## 目标

为 Alphapedia 刷新资料提供简体中文宝可梦名称，并在管理后台提供可持久化、可测试、不会泄露完整 Webhook 的企业微信机器人设置。现有实时情报、审核、重试队列和外部资料同步继续工作。

## 中文名称

资料同步器在现有三个 JSON 请求之外读取 Alphapedia 的 `/static/translations/zh/pokemon-species-zh.json`。每次同步在同一事务中更新刷新资料和英文到中文的名称映射；任一请求失败时不替换上次成功缓存。

`external_catalog` 保存英文原名和中文显示名。资料接口返回 `pokemon`（中文名，缺失时回退英文）与 `pokemonOriginal`（英文原名）。查询同时匹配中英文名和地点。页面以中文为主标题，英文原名作为辅助信息。

实时情报保持当前存储值不变，避免修改玩家历史数据。序列化事件和生成企业微信消息时，服务端用名称映射翻译已知英文名；玩家直接提交的中文名保持原样。搜索实时情报时同时匹配存储名称和映射后的中文名。

## 企业微信设置

管理后台新增“推送设置”标签。管理员可以查看启用状态、是否已配置、脱敏标识、队列统计、最近发送时间和最近错误；可以保存新 Webhook、停用推送、清除配置和发送测试消息。

完整 Webhook 只在管理员保存请求中出现一次。所有读取接口和审计记录只包含启用状态与脱敏标识。Webhook 继续使用既有严格校验：仅允许 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...`。

## 密钥与持久化

新增 `app_settings` 表保存设置。Webhook 使用 AES-256-GCM 加密，密文包含随机 IV 与认证标签。加密密钥来自 `SETTINGS_ENCRYPTION_KEY`，格式为 64 位十六进制或 Base64 编码的 32 字节值。密钥不写入数据库、日志、接口或备份说明。

若未提供加密密钥，管理员仍可查看环境变量 Webhook 的启用状态和发送测试消息，但网页不能保存 Webhook；设置页明确提示需要配置密钥。已有 `WECOM_WEBHOOK_URL` 作为后备值，数据库设置优先。清除数据库配置后恢复使用环境变量值；管理员可以停用推送而不删除密文。

通知服务每次发送和入队前读取当前有效设置，因此保存后立即生效，无需重启。启用机器人不会补发启用前未入队的历史事件。

## API

- `GET /api/v1/admin/settings/notifications`：返回脱敏设置和通知队列状态。
- `PUT /api/v1/admin/settings/notifications`：保存 `{enabled, webhookUrl?}`。空缺 Webhook 表示保留现有值。
- `DELETE /api/v1/admin/settings/notifications/webhook`：删除数据库中的机器人配置。
- `POST /api/v1/admin/settings/notifications/test`：向当前有效机器人发送固定测试消息，返回成功或经过清理的错误。

所有接口要求管理员会话、Origin 与 CSRF 校验，并受现有限流和请求大小限制。

## 错误处理

Webhook 无效、加密密钥缺失或测试发送失败时返回中文错误，不包含 URL、key、响应正文或密文。数据库密文无法解密时将推送视为未配置，设置状态显示配置错误；后台工作线程保持运行。修改设置和通知入队分别使用事务，既有重试、发送间隔和最多六次尝试保持不变。

## 界面

管理后台的第四个标签为“推送设置”。表单使用密码输入框，不回填现有 Webhook。已配置时显示脱敏标识和“更换机器人”；未配置时显示输入提示。启用开关、保存、发送测试消息和清除配置均提供忙碌状态和明确反馈。手机页面保持单列，不显示实现细节或密钥内容。

## 验证

后端测试覆盖中文映射、中文与英文搜索、翻译回退、同步失败保留缓存、密文不含明文、错误密钥处理、管理员权限、保存后即时生效、环境变量后备、停用、清除和测试消息。企业微信测试继续覆盖去重、重试、重启恢复和凭据清理。浏览器测试覆盖中文名称展示与管理员设置完整流程。最后运行全部 Node 测试、TypeScript/Vite 构建和 Playwright 测试。
